GitHub-Zugang

Damit die App die ESP-Logs aus deinem privaten Repo laden kann, braucht sie einen GitHub-Schlüssel: auf GitHub einen „Fine-grained token“ anlegen, nur für das Repo Ioniq6_obd, Berechtigung „Contents: Read-only“. Er bleibt nur auf diesem Gerät.

–
Ziehen zum Zoomen, Doppelklick zurück
Noch kein Log geladen Wähle links eine Fahrt aus, zieh eine CSV-Datei hierher oder trag unter „GitHub-Zugang“ deinen Schlüssel ein, dann erscheinen die Logs vom ESP.

Dateien, die du öffnest, bleiben auf diesem Gerät und werden nirgends hochgeladen. Die Geschwindigkeit kommt vom Fahrzeugrechner, bei alten Logs ist sie aus der Drehzahl berechnet. Restenergie, Isolation, Temperaturen, Ladesäule und Ladestatistik liest die App aus den Rohantworten im Log; die Zuordnung stammt teils aus OBDb Hyundai-IONIQ-6 (CC BY-SA 4.0).
